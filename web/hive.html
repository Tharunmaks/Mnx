Add a Bee

A Bee's card: its name, one-line skill, the tools it may use and whether it needs your OK. Every Bee gets its own computer: a terminal, browser storage, files and 24/7 jobs, on this server or on any cloud server you've connected. A Bee can make its own Bees too.

Computer

A new size restarts the Bee's computer; its files and jobs stay. Moving it to another server starts a fresh folder there; the old files stay where they were. Vortex OS gives the Bee a desktop (open it from its Cell); Plain Linux is terminal only.
