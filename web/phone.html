The Phone Drone runs in Termux on your Android phone and dials out to this Hive. It works over mobile data; nothing needs to reach into your phone.

  1. Install Termux and Termux:API from F-Droid, then in Termux: 
    pkg install python android-tools termux-api python-pillow
pip install websockets
curl -O
  2. For screen control (tap, type, open apps): Settings → Developer options → Wireless debugging → Pair device with pairing code, then: 
    adb pair localhost:<pair port> <code>
adb connect localhost:<port>
    Or use Shizuku and add --backend shizuku.
