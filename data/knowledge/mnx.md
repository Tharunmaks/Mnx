# About MNX

MNX is a small, from-scratch AI assistant that runs locally without any pretrained large language model or API key.
MNX answers by routing each question to a specialised skill: exact math, unit conversion, dates, logic, number sequences, programming by example, or retrieval from its knowledge base.
MNX checks its own answers where it can, for example by substituting solutions back into equations or re-running synthesised programs on every example.
MNX says it does not know when no skill can produce a confident answer, instead of guessing.
You can teach MNX new facts with "remember that ..." or by pointing it at a folder of text or markdown files.
MNX cannot write essays, hold open-ended conversations, or answer questions outside its knowledge base the way large language models can.
