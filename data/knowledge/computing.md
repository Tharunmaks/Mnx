# Computing

## Hardware and systems

A CPU (central processing unit) executes the instructions of a computer program.
RAM (random-access memory) is fast, volatile memory that holds data a running program is using.
A GPU (graphics processing unit) performs many simple calculations in parallel, which is why it is used to train neural networks.
A bit is a single binary digit, 0 or 1; a byte is 8 bits.
An operating system manages hardware and runs programs; examples are Linux, Windows and macOS.
Linus Torvalds created the Linux kernel in 1991.
The World Wide Web was invented by Tim Berners-Lee in 1989 at CERN.
HTTP (Hypertext Transfer Protocol) is the protocol web browsers use to fetch pages; HTTPS is HTTP encrypted with TLS.
TCP/IP is the suite of protocols that the internet is built on.
DNS (Domain Name System) translates domain names such as example.com into IP addresses.

## Programming

Python is a high-level programming language created by Guido van Rossum and first released in 1991.
JavaScript was created by Brendan Eich in 1995 and runs in every web browser.
C was developed by Dennis Ritchie at Bell Labs in the early 1970s.
Git is a distributed version control system created by Linus Torvalds in 2005.
A compiler translates source code into machine code before it runs; an interpreter executes code directly.
Recursion is when a function calls itself to solve smaller instances of the same problem.
A hash table stores key-value pairs and gives average O(1) lookup time.
A stack is a last-in, first-out (LIFO) data structure; a queue is first-in, first-out (FIFO).

## Algorithms

Binary search finds an item in a sorted list in O(log n) time by repeatedly halving the search range.
Merge sort and heapsort sort n items in O(n log n) time in the worst case.
Quicksort runs in O(n log n) time on average but O(n²) in the worst case.
Bubble sort and insertion sort take O(n²) time in the worst case.
Dijkstra's algorithm finds the shortest paths from a source node in a graph with non-negative edge weights.
Big-O notation describes how the running time or memory of an algorithm grows with the input size.
P versus NP asks whether every problem whose solution can be checked quickly can also be solved quickly; it is unsolved.

## Artificial intelligence

Machine learning is a field of AI in which systems learn patterns from data instead of following hand-written rules.
A neural network is a model made of layers of weighted connections, trained by gradient descent using backpropagation.
The transformer architecture was introduced in the 2017 paper "Attention Is All You Need" by Vaswani and colleagues.
A large language model (LLM) is a transformer trained on large amounts of text to predict the next token.
Retrieval-augmented generation (RAG) lets a model look up relevant documents at answer time instead of memorising every fact in its weights.
Knowledge distillation trains a small student model to imitate a larger teacher model.
Overfitting happens when a model memorises its training data and fails to generalise to new data.
